= ECA NOTIFICATION SERVICE
:toc:
:toc-title: Оглавление

== 1. Описание

В данном документе приведено описание API для отправки уведомлений.

== 2. Описание очередей

Ниже приведено описание очередей:

[options="header"]
|===
|Название очереди|Описание
|queue-push-events
|Название очереди для отправки пуш уведомления
|queue-email-events
|Название очереди для отправки email сообщений
|===

== 3. Описание формата сообщений

=== 3.1. Пример сообщения для уведомления пользователя

[source,json]
----
{
  "pushType": "USER_NOTIFICATION",
  "requestId": "1d2de514-3a87-4620-9b97-c260e24340de",
  "correlationId": "98a57ab7-6494-4d9d-b793-c807fdf02692",
  "messageType": "CLASSIFIER_CONFIGURATION_CHANGE",
  "messageText": "Добавил настройки классификатора [Логистическая регрессия] в конфигурацию [2536]",
  "initiator": "admin",
  "receivers": [
    "user"
  ],
  "additionalProperties": {
    "classifiersConfigurationId": "250"
  }
}
----

=== 3.5. Пример запроса отправки email

[source,json]
----
{
  "requestId": "7c798c0e-251f-41cb-82b0-e8a371718b60",
  "correlationId": "1cec4e54-0f46-4d70-ad19-a8f9f1a0e33c",
  "receiver": "test@mail.ru",
  "templateCode": "NEW_EXPERIMENT",
  "variables": {
    "requestId": "1cec4e54-0f46-4d70-ad19-a8f9f1a0e33c",
    "experimentType": "KNN",
  },
  "priority": 1,
  "user": "admin"
}
----

== 5. Описание шаблонов email сообщений

[options="header"]
|===
|Код шаблона|Описание|Обязательные параметры
|TIMEOUT_EXPERIMENT
|Сообщение о таймауте эксперимента
|experimentType, requestId, timeout
|FINISHED_EXPERIMENT
|Сообщение о завершенном эксперименте
|experimentType, requestId, downloadUrl
|IN_PROGRESS_EXPERIMENT
|Сообщение о поступлении эксперимента в работу
|experimentType, requestId
|TFA_CODE
|Сообщение с кодом подтверждения для 2FA
|tfaCode
|NEW_EXPERIMENT
|Сообщение о новом эксперименте
|experimentType, requestId
|USER_LOCKED
|Сообщение о блокировке учетной записи
|-
|NEW_USER
|Сообщение с учетными данными нового пользователя
|userName, password
|EMAIL_CHANGED
|Уведомление на старую почту об успешном изменении Email в личном кабинете Eca - service
|newEmail
|CHANGE_PASSWORD
|Сообщение с подтверждением изменения пароля в личном кабинете Eca - service
|validityMinutes, confirmationCode
|ERROR_EXPERIMENT
|Сообщение о завершении эксперимента с ошибкой
|experimentType, requestId
|PASSWORD_CHANGED
|Сообщение с успешным изменением пароля в личном кабинете Eca - service
|-
|PASSWORD_RESET
|Сообщение с успешным сбросом пароля в личном кабинете Eca - service
|-
|USER_UNLOCKED
|Сообщение о снятии блокировки учетной записи
|-
|CANCEL_EXPERIMENT
|Сообщение о прерывании построения эксперимента
|experimentType, requestId
|CHANGE_EMAIL
|Уведомление на старую почту о запросе изменения Email в личном кабинете Eca - service
|newEmail, revokeChangeEmailRequestUrl
|RESET_PASSWORD
|Сообщение со ссылкой для сброса пароля
|validityMinutes, resetPasswordUrl
|CHANGE_EMAIL_CONFIRM_NEW_EMAIL
|Сообщение с подтверждением изменения Email в личном кабинете Eca - service
|validityMinutes, confirmationCode
|EMAIL_CHANGED_NEW_EMAIL_CONFIRMED
|Сообщение с успешным подтверждением изменения Email в личном кабинете Eca - service
|-
|SET_PASSWORD_CONFIRMATION_CODE
|Сообщение с кодом подтверждения для установки постоянного пароля
|confirmationCode
|===
